# Data directory

- `rwanda_national_park_visits_2005_2024.csv`: 60 real annual park-level observations transcribed from NISR Rwanda Statistical Yearbook 2025, Table 9.1. The table credits RDB as the source. It is aggregate visitation data, not individual permit records.
- `anonymous_visitor_survey_template.csv`: blank structure for a possible anonymous survey. It contains no collected responses. Obtain lecturer/institutional and relevant operator permission before collecting any data. Target at least 200 valid responses if approved. Do not collect direct identifiers or fabricate answers.

Source: https://statistics.gov.rw/sites/default/files/documents/2025-12/RWANDA_STATISTICAL_YEARBOOK_2025.pdf
